# Validation scope

## Inherited scientific evidence

S26 reran the selected Liujia main chains from compiled inputs, not old predictions:
78 accepted RF fits, 13 temperature fits, 914 checks with no failures, and
394 saved arrays with zero differing elements. The initial mismatched-environment
attempt and 78 failed checks remain in the author-held historical record.
Exact matched replay used Python 3.13.9 / scikit-learn 1.7.2, not the main
Python 3.12.10 / scikit-learn 1.8.0 configuration. These are two complete
environments; the comparison does not isolate one library's causal effect.
FORCE/KGS retain earlier evidence scopes and are not retrained here.

## Current interface tests

Tests check config/path handling, environment mismatch rejection, bundled imports,
stage dispatch, fresh-output protection, foreign-cache detection, stage order,
generated QC/features, examples and array comparison. Scientific calls in
dispatch tests are mocked; real RF fitting is prohibited. Inherited tests cover
rules, interpolation, budgets and generated external CSV/ZIP/LAS fixtures.
Saved research aggregates are not part of the 42 unittest cases and are excluded
from this public package. The separate historical full readback CLI needs those
tables; tools/verify_synthetic.py checks only the included synthetic fixtures.
Preservation compares executable ASTs, not just filenames. The public-release
audit also compares all baseline Python bytes. Current execution and archive
readback results, rather than historical claims, are in VALIDATION_SUMMARY.json.

## Boundaries

This revision performs no model training, temperature fitting, full-data replay,
bootstrap analysis, geological interpretation or manuscript result update.
The portable orchestrator has not undergone a new 78-fit end-to-end run:
scientific functions inherit S26 acceptance, changed plumbing is tested separately.
Installation alone does not certify bitwise scientific replay; software/OS builds
and input identity matter as well as seeds.

Generation labels results COMPUTED_NOT_INDEPENDENTLY_ACCEPTED. The optional NPZ
comparator checks keys/shapes/dtypes/values, reports finite differences and applies
no blanket tolerance. Discrete classes, rankings, selected points, capture counts
or conclusion-direction changes require investigation, not a wider tolerance.

MIT selection and the request for public software release are complete.
Actual publication, controlled-input access and journal submission are separate
steps. Software tests grant no additional data rights or publication evidence.
